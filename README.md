# ShopMaster 🛒 — Boutique Online

Tienda virtual de estilo boutique que consume la API pública [FakeStoreAPI](https://fakestoreapi.com/products), con carrito de compras, pasarela de pago simulada y ticket térmico en PDF.

**🔗 Demo:** https://sohanygalan.github.io/shopmaster/

## ✨ Funcionalidades
- Catálogo con filtros por categoría y buscador en vivo
- Ventana de detalle con imagen ampliada, valoración y selector de cantidad
- Carrito con cantidades editables, eliminación y total (guardado en LocalStorage)
- Pasarela de pago simulada con validación (Luhn, vencimiento, CVV)
- Ticket de compra en PDF de 80 mm con fuente monoespaciada (jsPDF)
- Diseño responsivo con animaciones suaves

## 🧩 Tecnologías
HTML5 · CSS3 · JavaScript (ES6+) · Bootstrap 5 · Font Awesome 6 · jsPDF · Fetch API · LocalStorage

## 🧪 Datos de prueba para el pago
`Ana Pérez` · `4242 4242 4242 4242` · `12/30` · `123`

> Pago simulado: no se realiza ningún cobro ni se guardan datos de tarjeta.
